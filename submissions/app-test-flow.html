MatchProof App Test Flow

Step-by-step verification checklist for the deployed TxLINE-powered World Cup data console.

App URL
https://matchproof.onrender.com
Mode
Live TxLINE mode, service level 12
Private judge/operator note: live mutations require the temporary MATCHPROOF_OPERATOR_KEY. Share it only in private hackathon submission notes, never in GitHub or public docs.

Best Time To Test

  • Before a match: best for fixtures, scheduled score snapshots, UI, replay, audit, and guarded proof behavior.
  • During a live match: best for stream worker, live score updates, match-state signals, and proof/stat validation if Stats becomes non-empty.
  • After a match: best for replay, historical scores, audit trail, and stored evidence review.

If only one test window is available, test during a live match. If no live match is available, scheduled fixture data is still acceptable; state clearly that MatchProof stores and replays the TxLINE payloads currently available.

End-to-End Test Flow

1. Open the site

https://matchproof.onrender.com
Expected: landing page loads; logo matches favicon; desktop header stays fixed; mobile header scrolls with the page.

2. Check application health

https://matchproof.onrender.com/api/health
Expected: "ok": true, "mode": "live", "hasGuestJwt": true, and "hasApiToken": true.

3. Verify Settings

Open Settings.

Expected: network is mainnet, service level is 12, TxLINE API origin is correct, Mode Control shows live mode, and operator key input is available.

4. Sync fixtures

Open Command Center, paste the private operator key, then click Sync fixtures.

Expected: real TxLINE fixtures are stored, fixture count updates, no 401, and Audit Log records fixture ingestion.

5. Inspect fixtures

Open Fixtures, then open one fixture.

Expected: numeric fixture IDs such as 18187298; World Cup or Friendlies rows; fixture monitor opens with raw metadata.

6. Ingest score snapshot

Return to Command Center, paste the operator key if needed, choose a real numeric fixture, and click Score snapshot.

Expected before match: scheduled score rows may be stored, often 0-2 updates, with no crash.
Expected during match: score rows update and match-state signals may appear.
Expected after match: stored snapshot or historical data remains inspectable.

7. Review Match Monitor evidence

Open the fixture you just ingested.

Expected: stored TxLINE score payloads appear under updates, raw JSON evidence is inspectable, and deterministic agent signals appear if rules detected changes.

8. Review Signals

Open Signals.

Expected: signals show severity, title, evidence, source update IDs, and status. If no live match-state changes exist, an empty signal set is acceptable.

9. Test Proof Console

Use a fixture ID, sequence from a stored update, and a stat key from raw payload Stats if available.

Expected before match: if Stats is empty, proof may fail gracefully and record a failed or unsupported attempt.
Expected during/after match: if TxLINE returns proof material, status should become proof_received.

10. Use Replay Lab

Open Replay Lab and test Start, Step, Pause, and Reset.

Expected: replay walks through stored updates. If no updates exist, ingest a score snapshot first.

11. Inspect Audit Log

Open Audit Log.

Expected: fixture sync, score ingestion, proof attempt, replay, and worker events appear as traceable audit evidence.

12. Test Stream Worker during a live match

In Command Center, paste the operator key, click Start worker, then later click Stop worker.

Expected during match: stream updates may be captured and audited.
Expected before match: worker may connect but receive no messages; this is normal if there are no live score events.

13. Verify App Events SSE

https://matchproof.onrender.com/api/stream/app-events
Expected: text stream begins with event: status and includes "mode":"live".

14. Confirm live-mode guards

https://matchproof.onrender.com/api/export

Expected: 403 in live mode.

curl -X POST https://matchproof.onrender.com/api/demo/seed

Expected: 409 in live mode.

Final Demo Path

  1. Landing page.
  2. Health and Settings showing live TxLINE credentials.
  3. Command Center fixture sync.
  4. Fixtures page showing real World Cup fixtures.
  5. Score snapshot for one fixture.
  6. Match Monitor raw TxLINE evidence.
  7. Signals.
  8. Proof Console with honest proof status.
  9. Replay Lab.
  10. Audit Log as final evidence trail.
